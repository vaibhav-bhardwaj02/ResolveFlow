# ResolveFlow

## Smart Complaint & Service Management Portal

ResolveFlow is an enterprise-grade Complaint & Service Management Portal developed using Java and Spring Boot. The system allows customers to register complaints, administrators to manage and assign complaints, and support agents to resolve them efficiently.

---

## Technology Stack

- Java 21
- Spring Boot
- Spring Core
- Spring MVC
- Spring Data JPA
- Hibernate
- JDBC
- MySQL 8.4
- REST API
- JSP
- Servlets
- AJAX
- Bootstrap 5
- Maven
- Git & GitHub
